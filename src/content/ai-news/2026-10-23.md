### 1. Anthropic 推出常驻个人 Agent Claude Duet，Dan Shipper 实测两周

[查看原文](https://x.com/danshipper/status/2112997559463506059) · 来源：Dan Shipper (@danshipper)

Dan Shipper 说 Anthropic 发布了 Duet，一个常驻个人 agent，独立 app 覆盖 iOS、Android 和 web；它按工作/生活场景分频道而不只是一个聊天框，带 todo list 跟踪状态，能直接在 app 内写文档和 slides，并继承 Claude 账号的记忆、技能和已连应用。他用两周后从几乎只用 ChatGPT 变成 ChatGPT 和 Claude 大约五五开，近一年里第一次这么高频率用 Anthropic。他的保留很具体：还没法当幕僚长，能看到我电脑上的 Claude 会话但不能指挥它；邮件草稿比 dot 差，语音只支持转录不能对话。我的判断是，Duet 的核心实验是把“该你介入的时刻”交给模型判断，这比多接几个工具更接近真实工作流，但这些短板也说明它现在适合尝鲜、不适合当唯一主力。

### 2. Claude Duet 的产品定位：Opus 5.5 判断什么需要你、什么可以等

[查看原文](https://x.com/claudeai/status/2112984666437546104) · 来源：Claude (@claudeai)

Anthropic 官方说明 Duet 是围绕 Claude Opus 5.5 设计的，主要能力是判断什么需要你介入、什么可以等、什么时候先确认，并且继承 Claude 账号里的记忆、技能和已连接应用，所以几乎不用配置。这和 Dan Shipper 的实测能对上：Duet 的价值不在于更会聊天，而在于替你划优先级。我看这条的意义是把产品意图说清楚了，用模型做分诊而不是做更长的对话。判断是，这种常驻 agent 的门槛在判断质量，不接更多 API；一旦误判紧急程度，用户会比不用更累，所以官方自己也承认早期会误判紧急度。

### 3. Vercel 把 DeepSeek v4.1 Flash 接进 Token Pass，定位跑 subagent

[查看原文](https://x.com/rauchg/status/2113010010766913815) · 来源：Guillermo Rauch (@rauchg)

Guillermo Rauch 说 DeepSeek v4.1 Flash（1017）已进入 Vercel 的 Token Pass，卖点是快、便宜得离谱，并且提供零数据保留，适合用来跑由更大更贵模型规划计划、再交给它执行的 subagent；他开玩笑说把 TypeScript 移植到 Rust 十次也用不完额度。我看这条的实质是成本结构设计：规划用贵模型、执行用便宜模型，这是 agent 产品里最直接的可控成本杠杆。判断是，subagent 用便宜模型会变成默认架构，问题从用不用转移到怎么把规划质量稳住，避免下层模型机械执行错误计划。

### 4. Aaron Levie：安全将成为 agent 最大的工作负载之一

[查看原文](https://x.com/levie/status/2112964214818283917) · 来源：Aaron Levie (@levie)

Aaron Levie 认为网络安全会是 AI 最深远的方向之一：我们现在有一支不知疲倦的团队，可以去发现、修补或攻击任何系统和软件；防守方用 agent 找存量风险和异常模式，攻击方用同一套能力加速找洞。他预测这个循环会用掉比现在想象多 100 倍的 token，因为可以扫每一条日志、看每一行代码、过每一段流量。我的判断是，这条给了 agent 产品一个很具体的需求函数：不是做更聪明的单次回答，而是高频、大范围、持续运行的扫描与复核，这直接推到 infra 的吞吐和成本，也解释了为什么他紧接着说企业会更在意怎么管住网络、系统、数据和身份。

<a id="20261023-05"></a>

### 5. Aaron Levie：AI 创造的岗位，看安全行业就够了

[查看原文](https://x.com/levie/status/2113137032633757773) · 来源：Aaron Levie (@levie)

Levie 接着讲 AI 会带来的岗位：网络安全会成为企业接下来最大的投资方向之一；即使工作变得更 agentic、更自主，仍然需要更多人去把 agent 对准最关键的任务、复核发现、打补丁、响应事件。这段和上一条是同一组观点，但落点更具体，讲的是人怎么和 agent 分工。我看这条的价值是给做安全 agent 的产品一个组织层面的提示：卖点不是替代分析师，而是让分析师处理被 agent 收敛过的高优先级队列。判断是，安全 agent 的体验重点会往复核与处置界面走，而不是只比谁发现的洞多。

### 6. Vercel 提前部署 WAF 缓解措施应对 php2shell，提醒补丁后重部署

[查看原文](https://x.com/rauchg/status/2112989629536440400) · 来源：Guillermo Rauch (@rauchg)

Guillermo Rauch 说这次 php2shell 漏洞的应对是行业提前几周协同完成的，Vercel 部署了 WAF 缓解措施，已经成功拦截针对 PHP 源站的攻击尝试，并提醒假设还会有更多漏洞，把补丁后重部署当成肌肉记忆来练。这条给 builder 的实用信息是：平台层的 WAF 规则可以先于官方补丁生效，但用户侧仍要保证能快速重部署。我的判断是，这类事件正在把部署速度和回滚能力变成安全能力的一部分，不是单独的运维指标；平时不练快速重部署，出事时 WAF 只能兜住一部分。

### 7. Peter Steinberger：本周的 PHP 漏洞是 GPT-5.6 Sol 发现的

[查看原文](https://x.com/steipete/status/2112913060709228764) · 来源：Peter Steinberger (@steipete)

Peter Steinberger 说这周会引发混乱的那个 PHP 漏洞，是 GPT-5.6 Sol 找到的。这条很短，但价值在于它把模型能力和真实安全事件对上号：不是 demo 里找注入，而是一个会造成实际影响的漏洞。我看下来，这比任何安全评测榜单都更能说明模型在代码审计上的可用性。判断是，模型找漏洞会先变成安全团队的常规工具之一，但发现之后的验证、补丁和部署仍然是人的工作，这也是为什么 Levie 那两条强调人还要更多，而不是更少。

### 8. Dan Shipper：每家公司需要一个 frontier team 专门追模型变化

[查看原文](https://x.com/danshipper/status/2113010761786175970) · 来源：Dan Shipper (@danshipper)

Dan Shipper 说追 AI 是份全职工作，所以每家公司需要一个 frontier team：这个团队负责跟着模型变化，其他人负责用他们学到的东西。他列了 Every 内部的具体做法，包括用 Opus 根据 Slack 消息和会议记录剪解释视频、有人给 AI 写作插件教读者是谁、有人做了个人 AI 编排器、有人做了无标签页浏览器。这条和那条播客是同一主题，我保留这条是因为它有可检验的细节。判断是，frontier team 的实质是把实验和交付拆开，避免全公司都在追新工具却不产出；难点是让实验结论真正传到一线工作流，而不是停在内部 demo。
