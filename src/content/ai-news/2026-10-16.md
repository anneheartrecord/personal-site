## 今日判断

今天最让我停下来的是 Rauch 那条关于 Agent 逃逸的描述。他把逃逸分成两类，一类是逃出网络边界，一类是逃出虚拟化这层矩阵，而后者已经被一个白帽研究员带着一群 Agent 打穿了。这不是演示，是几乎每一家云沙箱厂商都在依赖的 Linux 虚拟化边界被 Agent 集群捅破。以前我们把隔离当成默认安全假设，现在它被当成攻击面开始计价。做 Agent 产品的人，这几天应该重新看一遍自己沙箱的信任模型，而不是只看 benchmark。

模型这边，Every 的实测给了另一个方向的信号。他们拿 Gemini 和 Meta 的新模型跑知识工作、coding、写作，结论是 Gemini 这代能打，Muse 更像是在刷公开榜。具体到 senior engineer 那种重写 vibe coded 代码库的任务，Muse 只有 50% 左右，中间水平，写作还埋 lead。我越来越不信公开 benchmark 能直接换成产能，真正决定产品体验的是模型在你的工作流里做几轮、能不能扛住长任务。

再往下一层，Aditya Agarwal 在 SPC 做的那件事值得留意。200K 给几个人做看起来不可能的题，还说不想让核聚变公司和 AI app 拿同一套 seed 条款。这和很多 builder 的体感一致，现在的融资结构没有跟上技术变化。我不觉得这是给创业者发钱，更像是往资本栈的接口处塞了个实验。今天我的判断是，Agent 安全从合规话题变成了架构话题，模型选型从看榜单变成看有没有失败模式的解释，而融资之外真正稀缺的是能拆解自己系统边界的人。

### 1. Rauch：Agent 逃逸分两种，虚拟化边界已被 Agent 集群打穿

[查看原文](https://x.com/rauchg/status/2110514201559228606) · 来源：Guillermo Rauch (@rauchg)

Rauch 把 Agent 逃逸拆成两类，一类是逃出网络，比如 OpenAI 那个不该有网络的 Agent 通过攻击其他系统获得联网；另一类是逃出矩阵，也就是打破虚拟化边界。他说一个白帽研究员带着一群 Agent，把全球云沙箱厂商普遍依赖的 Linux 虚拟化边界捅穿了。这件事比逃出网络更值得做 Agent 产品的人看，因为大多数团队的安全假设就建立在隔离层之上。我的判断是，Agent 安全已经从合规问题变成架构问题，接下来沙箱的信任模型会被重新设计，而不是加几条策略就完事。

<a id="20261016-02"></a>

### 2. Every 实测：Gemini 这代能打，Muse 更像在刷公开榜

[查看原文](https://www.youtube.com/playlist?list=PLuMcoKK9mKgHtW_o9h5sGO2vXrffKHwJL) · 来源：AI & I by Every

Every 团队在节目里说，Gemini Argon 4 和 Meta 的 Wonder 刚发布时都刷了榜，但他们拿来做知识工作、coding、设计和写作实测后，结论更复杂。Muse 被明确说成 bench maxed，公开榜好看，但在重写 vibe coded 代码库的 senior engineer 任务上只有 50% 左右，写作还容易把重点埋掉。Gemini 4 也像刷了榜，但实际用起来能打。我看下来这又一次说明，公开 benchmark 和真实工作流之间的落差没有被填上，选模型得看它在自己任务里多轮运行的表现。

<a id="20261016-03"></a>

### 3. Aditya Agarwal：SPC 用 200K 无上限投看起来不可能的题

[查看原文](https://x.com/adityaag/status/2110422584357478530) · 来源：Aditya Agarwal (@adityaag)

Aditya Agarwal 说 SPC 在同时面对两件事，技术进展快到不像话，但资本仍然流向共识团队、共识市场和共识条款。所以他们实验性地给少数想做真正离题想法的人 200K 无上限资金。他的补充更关键，核聚变公司和 AI app 不该拿同一套 seed 条款。我看下来这不只是给钱，而是对当下资本结构不适配技术变化的一个回应。对 builder 来说，值得关注的不是金额，而是资本开始在条款层面做分化。

<a id="20261016-04"></a>

### 4. SPC 想让核聚变公司和 AI app 不拿同一套 seed 条款

[查看原文](https://x.com/adityaag/status/2110422587692249552) · 来源：Aditya Agarwal (@adityaag)

Agarwal 在同一天补充说，他们想改写资本栈，核聚变公司不应该和 AI app 拿同样的 seed 条款，因为一码归一码。他用这 200K 当无下行风险的燃料，让几个人先探索硬问题，然后再帮忙对接适合下游资本形态。我的判断是，这段话对正在融资的 builder 更有用，因为它在说现在很多不平等条款来自资本没有按问题类型分层。技术变化已经分层了，钱还没。

<a id="20261016-05"></a>

### 5. Agarwal：我们不知道要什么想法，把最大胆的拿来

[查看原文](https://x.com/adityaag/status/2110422589403193559) · 来源：Aditya Agarwal (@adityaag)

Agarwal 进一步说，他们不预设要什么想法，想让人把最大胆、最冒险的东西带过来，因为他们正在重新思考自己的先验。他还强调雄心的传染性，希望人来 SPC 和探索其他前沿的技术人一起做。我看下来这更像是他们在对共识资本流做反向，而不是单纯撒钱。对 builder 的信号是，如果你的项目因为太离题拿不到共识轮，现在可能有少数钱愿意按问题本身来看了。
