## 今日判断

我今天更关注的不是某个单点发布，而是 AI 正在从聊天窗口继续往工作区里搬。

只要进入真实工作区，问题就不会停留在模型聪不聪明。它要保存状态，要能被审查，要能复用过去的经验，也要知道哪些地方必须停下来等人确认。很多看起来很琐碎的产品问题，通常只会在真实高频使用后出现。

我的判断是，接下来值得跟踪的不是谁又喊了一个 agent 概念，而是谁能把这些脏活累活做扎实。好产品不是让 AI 看起来更神，而是让 builder 每天都敢把一部分工作交出去。

### 8. Skills API 继续升温，agent 能力开始从 prompt 迁移到可复用技能

[查看原文](https://x.com/garrytan/status/2089425134339961173) · 来源：Garry Tan (@garrytan)

Garry Tan (@garrytan) 关注 AI skills，说明 agent 工作流正在从一次性提示词，转向可复用、可组合、可管理的技能层。这个方向对 builder 很关键：真正可规模化的 agent 不是每次靠长 prompt 硬撑，而是把常用操作沉淀成稳定接口和能力包。后面需要持续观察各家是否会围绕 skill、MCP、文件系统和权限模型形成事实标准。
