## 今日判断

今天我更关注 coding tool 这一层的动作密度。OpenAI 和 Anthropic 的人在同一个时间窗口里讲怎么把 agent 放进真实代码和生产 loop，而不是讲模型分数。有用的信号是会话怎么续、上下文怎么切、失败后怎么回滚。这些不进 benchmark，却直接决定工具链要不要重写。

Replit 和 Box 两条放在一起看：Amjad 讲生成到部署还能压多短，Levie 讲企业里权限、审计、数据边界怎么跟会动手的 agent 共存。公司规模差很远，撞的是同一堵墙：agent 一旦能动手，产品问题立刻变成权限问题和回滚问题。我的判断是，做 agent 产品的团队优先级不是加更多 tool，而是先把执行记录、审批节点和回滚路径做成产品的一部分，否则 demo 很好、上线卡死。

官方账号发布稿普遍不如产品负责人补的几句：官方号讲有什么，一线讲一天跑几次、哪里会崩、哪些是坑。我今天选稿按这个标准：谁拿自己的活做样本，就留谁。给 builder 的动作是，别抄功能列表，抄他们踩过的坑。
